# Subject Rules

## Animals

Use:
- anatomy
- body proportions
- limbs
- ears
- tail
- posture
- expression

Example dog concepts:
running
fetching
guarding
greeting
sleeping
stretching

## Tools

Use:
- handles
- joints
- functional contact points
- mechanical geometry
- tool-specific construction

Example hammer concepts:
side profile
raised
striking
claw visible
carpenter use
isolated tool

Do not apply animal concept logic to tools.

## Objects

Use:
- recognizable construction
- purpose
- functional geometry

## Food

Use:
- defining shape
- recognizable surface
- preparation/use context where relevant

## Vehicles

Use:
- body
- wheels
- windows
- lights
- function
- structural geometry
