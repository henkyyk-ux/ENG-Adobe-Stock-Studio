# Skill: Differentiation Engine

Goal:
Prevent near-duplicate stock assets before image generation.

Compare candidate concept against:
- current series concepts
- relevant prior assets

Dimensions:
- pose
- orientation
- silhouette
- action
- structural logic
- use case
- prop
- expression
- composition intent

Color-only difference:
FAIL differentiation.

Minor rotation/flip/crop:
FAIL differentiation.

Output:
PASS
or
REVISE

If REVISE:
provide concrete concept changes.
