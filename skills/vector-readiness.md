# Skill: Vector Readiness

VECTOR_READY means:
The image has characteristics that support a later vector-production workflow.

Check:
- clear silhouette
- clean shapes
- relatively simple geometry
- closed forms
- controlled outlines
- limited shading complexity
- low unnecessary raster noise

VECTOR_COMPLETE means:
A genuine editable vector file exists and has passed technical validation.

Never convert VECTOR_READY into VECTOR_COMPLETE merely because the image looks vector-like.
