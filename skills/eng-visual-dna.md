# Skill: ENG Visual DNA

Purpose:
Keep generated assets visually coherent without forcing identical character designs.

Always prioritize:
- original 2D illustration
- vector-oriented appearance
- clean commercial readability
- strong silhouette
- controlled bold black outlines
- flat colors
- maximum two hard-edged cell-shading levels
- clean closed shapes
- minimal highlights
- generous negative space
- isolated/simple background

Avoid:
- photorealism
- painterly rendering
- 3D appearance
- soft gradients
- airbrush
- excessive texture
- glow
- glossy photorealistic eyes
- visual clutter
- accidental cropping
- stray marks
- watermark/signature/logo unless explicitly valid

Use subject-specific structural logic.

Consistency = visual language.
Consistency != identical anatomy/design.
