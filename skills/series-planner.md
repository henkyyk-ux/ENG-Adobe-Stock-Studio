# Skill: Series Planner

Input:
Natural language subject request.

Output:
One series plus 6–10 meaningful concepts.

Required series fields:
- series code
- series name
- subject
- subject type
- description

Required concept fields:
- asset ID
- concept title
- pose/orientation
- action/function
- expression if relevant
- marking/color
- prop/interaction
- commercial use
- differentiation notes

Rules:
- concepts must be commercially meaningful
- concepts must vary structurally
- do not create color-only variants
- use subject-specific logic
- avoid near-duplicates
- do not generate images during planning
