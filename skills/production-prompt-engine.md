# Skill: Production Prompt Engine

Build prompts in layers:

1. ENG Visual DNA
2. Subject-specific structural logic
3. Concept definition
4. Composition
5. Technical appearance
6. Negative rules
7. Adobe compliance
8. Differentiation constraints

The prompt engine must preserve structured source data.

Never hide critical production rules only inside an unstructured prompt.

The prompt must describe the intended asset without referencing protected characters, named artists, brands, or franchises.
