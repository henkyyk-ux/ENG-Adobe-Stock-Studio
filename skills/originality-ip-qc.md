# Skill: Originality / IP QC

Block or flag:
- recognizable existing character
- brand identity
- franchise identity
- copyrighted character
- trademark misuse
- celebrity likeness
- real-person identity when not intentionally supplied and permitted
- artist-specific style imitation
- deliberate resemblance to famous IP

Do not make speculative accusations.

If the result is uncertain and materially risky, mark for human review rather than claiming certainty.
